# Módulo 1: Estrutura Sequencial

1. Faça um Programa que mostre a mensagem "Alo mundo" na tela.
2. Faça um Programa que peça um número e então mostre a mensagem: "O número informado foi [número]".
3. Faça um Programa que peça dois números inteiros ou reais e imprima a soma.
4. Faça um Programa que peça as 4 notas bimestrais e mostre a média aritmética.
5. Faça um Programa que converta uma medida fornecida em metros para centímetros.
6. Faça um Programa que peça o raio de um círculo, calcule e mostre sua área (Fórmula: A = π * raio²; considere π = 3.14159).
7. Faça um Programa que calcule a área de um quadrado, em seguida mostre o dobro desta área para o usuário.
8. Faça um Programa que pergunte quanto você ganha por hora e o número de horas trabalhadas no mês. Calcule e mostre o total do seu salário no referido mês.
9. Faça um Programa que peça a temperatura em graus Fahrenheit, transforme e mostre a temperatura em graus Celsius.
   - Fórmula: C = 5 * ((F - 32) / 9)
10. Faça um Programa que peça a temperatura em graus Celsius, transforme e mostre em graus Fahrenheit.
   - Fórmula: F = (C * 9/5) + 32
11. Faça um Programa que peça 2 números inteiros e um número real. Calcule e mostre:
   - a) O produto do dobro do primeiro com metade do segundo.
   - b) A soma do triplo do primeiro com o terceiro.
   - c) O terceiro elevado ao cubo.
12. Tendo como dados de entrada a altura de uma pessoa, construa um algoritmo que calcule seu peso ideal, usando a fórmula:
   - Peso Ideal = (72.7 * altura) - 58
13. Tendo como dado de entrada a altura (h) de uma pessoa, construa um algoritmo que calcule seu peso ideal para ambos os sexos:
   - Para homens: (72.7 * h) - 58
   - Para mulheres: (62.1 * h) - 44.7
14. Faça um programa que calcule o salário líquido de um trabalhador a partir do valor da hora e do total de horas trabalhadas no mês. O programa deve deduzir:
   - 11% para o Imposto de Renda (IR)
   - 8% para o INSS
   - 5% para o Sindicato
   - Mostre: salário bruto, quanto pagou a cada imposto e o salário líquido final.
15. Faça um programa para uma loja de tintas. O programa deverá pedir o tamanho em metros quadrados da área a ser pintada. Considere que a cobertura da tinta é de 1 litro para cada 3 metros quadrados e que a tinta é vendida em latas de 18 litros, que custam R$ 80,00. Informe ao usuário a quantidade de latas de tinta a serem compradas e o preço total (arredonde a quantidade de latas para cima).
16. Faça um programa que peça o tamanho de um arquivo para download (em MB) e a velocidade de um link de Internet (em Mbps), calcule e informe o tempo aproximado de download do arquivo usando este link (em minutos).
